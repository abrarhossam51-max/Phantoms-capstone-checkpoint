# Phantoms-capstone-checkpoint
Titanic Survival Prediction – AI Capstone Project

 نبذة عن المشروع

يهدف هذا المشروع إلى بناء نظام ذكاء اصطناعي قادر على التنبؤ باحتمالية نجاة ركاب سفينة Titanic من حادث الغرق، اعتمادًا على مجموعة من البيانات الشخصية وبيانات الرحلة الخاصة بكل راكب.

يعتمد المشروع على مجموعة بيانات Titanic Dataset، ويستخدم تقنيات تعلم الآلة (Machine Learning) لتحليل البيانات واكتشاف الأنماط والعوامل التي قد تؤثر على فرص النجاة، مثل العمر، والجنس، ودرجة التذكرة، وعدد أفراد الأسرة.

 أهداف المشروع

- تطبيق المهارات والمفاهيم التي تم تعلمها خلال الأسابيع من الأول إلى الخامس.
- التعامل مع البيانات واستخراجها وتخزينها باستخدام SQLite.
- تنظيف البيانات وتجهيزها لتكون مناسبة لتدريب نماذج تعلم الآلة.
- تدريب ومقارنة نموذجين مختلفين على الأقل.
- تقييم أداء النماذج باستخدام مقاييس متعددة، وليس Accuracy فقط.
- تحديد ما إذا كانت المشكلة تحتاج إلى استخدام Deep Learning أم أن Machine Learning التقليدي كافٍ لحلها.

 مراحل تنفيذ المشروع

1. جمع البيانات وتخزينها: تحميل Titanic Dataset وتخزين البيانات داخل قاعدة بيانات SQLite.

2. تنظيف وتجهيز البيانات: معالجة القيم المفقودة، وتحويل البيانات النصية إلى بيانات رقمية، وتحديد الخصائص (Features) والهدف (Label).

3. تدريب النماذج ومقارنتها: تدريب نموذجين مختلفين على الأقل باستخدام نفس تقسيم بيانات التدريب والاختبار لضمان المقارنة العادلة.

4. تقييم الأداء: استخدام Confusion Matrix وPrecision وRecall وF1-Score لمقارنة النتائج وتحديد النموذج الأفضل.

5. تقييم الحاجة إلى Deep Learning: تجربة شبكة عصبية بسيطة ومقارنة أدائها مع نماذج Machine Learning التقليدية، ثم اتخاذ قرار هندسي بناءً على النتائج.

 النتائج النهائية

سيتم إضافة نتائج النماذج ومقاييس التقييم بعد الانتهاء من التدريب والمقارنة

 الخلاصة

يهدف هذا المشروع إلى بناء Pipeline متكامل لتعلم الآلة، بدايةً من جمع البيانات وتخزينها، مرورًا بالتنظيف والتدريب والتقييم، وصولًا إلى اتخاذ قرار هندسي يحدد أنسب التقنيات لحل المشكلة
